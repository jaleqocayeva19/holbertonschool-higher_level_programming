# JavaScript DOM Manipulation

## Description
This project covers the basics of JavaScript DOM (Document Object Model) manipulation, handling user events, modifying HTML elements and styles, and making HTTP requests using the Fetch API.

## Requirements
* All files are executed on Chrome browser (version 57.0 or later).
* All JS files end with a new line.
* Code complies with `semistandard` style guidelines.
* `var` is not used (`const` and `let` are used instead).
* HTML pages do not reload during DOM updates or data fetching.

## Files & Tasks

| File | Description |
| :--- | :--- |
| `0-script.js` | Changes the text color of the `<header>` element to red (`#FF0000`). |
| `1-script.js` | Changes the text color of the `<header>` element to red when `#red_header` is clicked. |
| `2-script.js` | Adds the class `red` to the `<header>` element when `#red_header` is clicked. |
| `3-script.js` | Toggles between `red` and `green` classes on `<header>` when `#red_header` is clicked. |
| `4-script.js` | Adds a new `<li>Item</li>` to `ul.my_list` when `#add_item` is clicked. |
| `5-script.js` | Updates the text of `<header>` to "New Header!!!" when `#update_header` is clicked. |
| `6-script.js` | Fetches the character name from the Star Wars API and displays it in `#character`. |
| `7-script.js` | Fetches and lists all movie titles from the Star Wars API into `ul#list_movies`. |
| `8-script.js` | Fetches "hello" translation from the API and displays it in `#hello` (imported in `<head>`). |
| `9-script.js` | Fetches "hello" translation based on browser language when `#btn_translate` is clicked. |
