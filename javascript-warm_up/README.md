# JavaScript - Warm up

This project serves as a basic introduction to JavaScript scripting. The goal is to master fundamental programming concepts such as variables, data types, loops, conditions, and functions before moving on to front-end development.

## 📝 Core Concepts Covered

* **Variables & Scope:** Understanding the crucial differences between `var`, `let`, and `const`.
* **Data Types & Operators:** Working with primitive types, objects, arrays, and arithmetic/logical operators.
* **Control Flow:** Implementing conditional statements (`if`, `if...else`) and loops (`while`, `for`, `break`, `continue`).
* **Functions:** Writing reusable blocks of code and understanding what a function returns by default.
* **Objects:** Basic dictionary (object) manipulation and file imports.
