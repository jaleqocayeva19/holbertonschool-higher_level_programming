# Python - Classes and Objects

This project covers the basics of Object-Oriented Programming (OOP) in Python, including classes, attributes, methods, getters, setters, and properties.

## Tasks

* **0-square.py**: Defines an empty class `Square`.
* **1-square.py**: Defines a `Square` class with a private instance attribute `size`.
* **2-square.py**: Adds type and value validation for `size`.
* **3-square.py**: Adds the `area()` method to calculate the area of the square.
* **4-square.py**: Adds getter and setter properties for `size`.
* **5-square.py**: Adds the `my_print()` method to print the square using `#`.
* **6-square.py**: Adds a private `position` attribute and updates `my_print()` to handle coordinates.

## Requirements

* Interpreted on Ubuntu 20.04 LTS using `python3` (version 3.8.5)
* Code style follows `pycodestyle` (version 2.7.*)
* All files are executable
