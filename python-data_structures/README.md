# Python - Data Structures: Lists, Tuples

## Description
This repository contains projects and practice tasks for **Python Programming** completed during the curriculum at Holberton School. This project focuses on understanding fundamental data structures in Python, primarily **Lists** and **Tuples**, their operations, and how to manipulate sequences efficiently.

---

## What I Learned
Through this project, I learned and practiced:
* What **lists** and **tuples** are, and how to use them effectively.
* The main differences and similarities between strings, lists, and tuples.
* Common built-in list methods and sequence operations.
* How to use lists as **stacks** (LIFO) and **queues** (FIFO).
* Writing cleaner code using **list comprehensions**.
* Concept of **tuple packing** and **sequence unpacking**.
* Using the `del` statement to remove elements.
* Best practices for code styling according to **pycodestyle** (PEP 8).

---

## Requirements
* **Operating System:** Ubuntu 20.04 LTS
* **Python Version:** Python 3.8.5
* **Code Style:** `pycodestyle` (version 2.7.*)
* **Executable Files:** All scripts are executable (`chmod +x <filename>`) and start with `#!/usr/bin/python3`.
