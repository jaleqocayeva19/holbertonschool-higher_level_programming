# Python - Exceptions

## Description
This project covers the fundamentals of handling errors and exceptions in Python. It teaches how to manage unexpected events gracefully during program execution using `try`, `except`, `else`, `finally`, and how to manually raise builtin exceptions.

## Learning Objectives
At the end of this project, you will be able to explain:
* The difference between syntax errors and exceptions.
* What exceptions are and how to use them.
* How to handle exceptions correctly using `try / except`.
* Why catching exceptions is useful to prevent program crashes.
* How to raise builtin exceptions using `raise`.
* How to perform clean-up actions using `finally`.

## Requirements
* **Environment:** Ubuntu 20.04 LTS with Python 3.8.5
* **Code Style:** `pycodestyle` (version 2.7.*)
* **File Format:** All files must end with a new line and start with `#!/usr/bin/python3`.
* **Permissions:** All files must be executable (`chmod +x <filename>`).

## Tasks Summary

| File | Description |
| --- | --- |
| `0-safe_print_list.py` | Prints `x` elements of a list safely using `try / except`. |
| `1-safe_print_integer.py` | Prints an integer using `"{:d}".format()` safely. |
| `2-safe_print_list_integers.py` | Prints the first `x` integers of a list safely. |

| `5-raise_exception.py` | Raises a `TypeError` exception. |
