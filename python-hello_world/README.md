# Python - Hello, World

## Description 
This repository contains Python scripts and exercises introduced during the **Python - Hello, World** module at Holberton School. The project covers the basics of Python 3, including environment setup, executing scripts, print formatting (f-strings, string formatting), and PEP 8 code style guidelines.

## Learning Objectives
By the end of this project, you are expected to be able to explain:
* Why Python programming is awesome
* Who created Python and why `Print` is a function in Python 3
* What is a Shebang line (`#!/usr/bin/python3`)
* How to use the Python interpreter and run scripts
* How to print text and variables using `print()`
* How to format strings using f-strings and `.format()`
* What PEP 8 is and how to check code style using `pycodestyle`
