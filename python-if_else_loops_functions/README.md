# Python - if/else, loops, functions

This repository contains exercises for learning core Python programming concepts, including conditional statements (`if`, `elif`, `else`), loops (`while`, `for`), functions, and ASCII character manipulation without external modules.

---

## 🛠️ Requirements

* **Environment:** Ubuntu 20.04 LTS
* **Python Version:** Python 3.8.x
* **Style Guide:** Code must adhere to PEP 8 (tested with `pycodestyle` version 2.8.*)
* **Execution:** All script files must be executable (`chmod +x <filename>`)
