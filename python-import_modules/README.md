# Python - import & modules

## Description
This project focuses on understanding how imports, modules, command line arguments, and built-in functions work in Python 3.

## Requirements
* Allowed editors: `vi`, `vim`, `emacs`
* All files are interpreted/compiled on Ubuntu 22.04 LTS using `python3` (version 3.10.*)
* All files end with a new line
* The first line of all files is strictly `#!/usr/bin/python3`
* Code follows the `pycodestyle` style guide (version 2.7.*)
* All files are executable (`chmod +x <filename>`)
