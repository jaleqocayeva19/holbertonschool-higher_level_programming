# Python - More Data Structures: Set, Dictionary

This project focuses on working with more advanced data structures in Python, specifically **Sets** and **Dictionaries**, as well as functional programming concepts like `lambda`, `map`, `filter`, and `reduce`.

## 📝 Core Concepts Learned

* **Sets:** Handling unique elements, removing duplicates, and performing set operations (union, intersection, difference, symmetric difference).
* **Dictionaries:** Managing key-value pairs, adding, modifying, and deleting dictionary elements.
* **Lambda Functions:** Creating anonymous, single-line functions for cleaner code execution.
